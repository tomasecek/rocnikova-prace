# 🐔 Automatická dvířka – ESP32

Ročníkový projekt pro ovládání automatických dvířek pomocí ESP32 přes vlastní webové rozhraní. 
Jednoduché manuální i automatické řízení s možností nastavení časového rozvrhu.
